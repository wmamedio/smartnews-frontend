## 🎭 Animation Sequences

### Page Load (Preview Mode)
```
1. [0.0s] CreatorInfoSection fades in from top
           ↓
2. [0.2s] Value prop section fades in
           ↓
3. [0.3s] Subscribe button fades in
           ↓
4. [0.4s] Preview banner fades in
           ↓
5. [0.5s] Newsletter card fades in
           ↓
6. [0.6s] Item 1 slides in from bottom
7. [0.7s] Item 2 slides in from bottom
8. [0.8s] Item 3 slides in from bottom (with teaser)
           ↓
9. [0.9s] Bottom CTA section fades in
```

### Subscribe Button Click
```
1. Button: scale(0.95) for 100ms
2. If unauthenticated:
   → AuthModal slides up from bottom (300ms)
3. If authenticated:
   → Button shows loading spinner
   → API call
   → Success toast appears top-right
   → Button changes to "✓ Subscribed"
   → Page updates to full access mode (500ms transition)
```

### Hover Interactions
```
Card hover:
- border-color: transparent → primary/20 (150ms)
- box-shadow: none → shadow-md (150ms)

Button hover:
- box-shadow: shadow-lg → shadow-xl (200ms)
- scale: 1 → 1.02 (200ms)

Avatar hover:
- scale: 1 → 1.05 (200ms)
```

## 🧪 User Testing Scenarios

### Scenario 1: First-time Visitor
**Goal**: Subscribe within 60 seconds

1. Land on page → See creator section (5s)
2. Read bio, see subscriber count → Build trust (10s)
3. Scroll down → See preview banner (3s)
4. View first 2 items → Understand content quality (15s)
5. See teaser on 3rd item → Create FOMO (5s)
6. Click top Subscribe button → Auth modal (2s)
7. Complete sign-up → Return to page (15s)
8. Auto-subscribe → Success! (2s)

**Total Time**: ~57 seconds

### Scenario 2: Returning Visitor (Authenticated)
**Goal**: Subscribe within 15 seconds

1. Land on page → Recognize creator (3s)
2. Click Subscribe button → Immediate subscription (2s)
3. Toast notification → Confirmation (1s)
4. Page updates → Full access (1s)

**Total Time**: ~7 seconds

### Scenario 3: Subscribed User
**Goal**: Start consuming content immediately

1. Land on page → See "Subscribed" badge (1s)
2. Scroll down → All content visible (2s)
3. Click "Read More" → Open article (1s)

**Total Time**: ~4 seconds
