# Story 1.5: Frontend - Creator Dashboard & Analytics

## Story Status: 🚀 Ready for Development

## User Story

As a NEW creator who just signed up,
I want a dashboard that guides me through creating my first feed with clear explanations using the "playlist" analogy,
So that I understand what SmartNews does and can quickly start curating content without confusion.

As a creator with a feed but no sent newsletters,
I want to see my ready-to-publish content and easily share my public feed link,
So that I can send my first newsletter and start building my subscriber base.

As an ACTIVE creator with sent newsletters,
I want to see basic performance metrics and manage my feeds efficiently,
So that I can track growth and optimize my content strategy.

## Story Context

### Progressive Onboarding States

This dashboard adapts to three distinct user journey stages:

**STATE 1: New User (No Feeds)**

- Goal: Create first feed
- UI: Hero card with "What's a Feed?" explanation (playlist analogy)
- Primary CTA: "Create Your First Feed" (opens wizard modal)
- Hide: All stats, all feed previews

**STATE 2: Has Feed (No Newsletters Sent)**

- Goal: Complete profile + send first newsletter
- UI: Public URL share card (prominent) + feed items preview + profile completion alert
- Primary CTA: "Send Your First Newsletter"
- Hide: Stats cards

**STATE 3: Active Creator (Sent Newsletters)**

- Goal: Grow and optimize
- UI: 4 basic stat cards + feed management + public URL sharing
- Primary CTA: Feed actions (edit, schedule, send)
- Show: Simple metrics only (total feeds, subscribers, revenue, open rate)

### Integration Points

- **Backend API**: `https://localhost:8000/` (use NEXT_PUBLIC_API_URL)
- **Feed Data**: `/feeds` endpoint (existing)
- **Feed Items**: `/feed-items?status=ready_for_publish` (existing)
- **Profile**: `/creator/profile` (existing)
- **Stats**: Basic counts only (no complex analytics APIs needed)

### Technology Stack

- **Framework**: Next.js 15.5 with App Router
- **Layout**: CSS Grid 2-column desktop (66% / 33%), single-column mobile
- **UI Components**: shadcn/ui ONLY (Card, Button, Input, Badge, Select, Alert)
- **State Management**: React Query + useMemo for state detection
- **Charts**: NONE (just simple number displays)
- **Libraries**: date-fns for time formatting ONLY

## Acceptance Criteria

### Functional Requirements

#### 1. State Detection Logic

- Automatically detect user state: `new_user | has_feed | active`
- Detection based on: feed count + newsletter send history
- Transition smoothly between states without page reload

```typescript
type DashboardState = "new_user" | "has_feed" | "active";

function getDashboardState(feeds: Feed[]): DashboardState {
  if (!feeds || feeds.length === 0) return "new_user";

  const hasSentNewsletter = feeds.some((feed) => feed.total_newsletters_sent > 0);

  return hasSentNewsletter ? "active" : "has_feed";
}

function isProfileComplete(profile: Profile): boolean {
  return !!(
    (profile.name || (profile.first_name && profile.last_name)) &&
    profile.bio &&
    profile.avatar
  );
}
```

#### 2. STATE 1: New User Dashboard

**Layout**: Single centered card (max-w-2xl)

**Hero Card Content**:

- Music icon in colored circle (h-20 w-20, bg-primary/10)
- Title: "What's a Feed?" (text-3xl)
- Explanation (3-4 sentences):
  > "Think of it like creating a **Spotify playlist**—but for content instead of music. You pick the **sources** (like artists), set **filters** (your vibe), and SmartNews automatically curates the best content for your subscribers."
- 3 numbered steps with icons:
  - 1. Add Sources (RSS feeds, blogs, YouTube)
  - 2. Set Your Vibe (AI filters by keywords)
  - 3. Auto-Send or Manual (Schedule or send when ready)
- Large primary button: "Create Your First Feed" (opens /feeds/create wizard)
- Secondary ghost button: "Or start by adding content sources →" (links to /content/sources)

**What to Hide**:

- All stats cards
- All feed preview sections
- All analytics

#### 3. STATE 2: Has Feed Dashboard

**Desktop Layout**: 2-column grid (grid-cols-3, left: col-span-2, right: col-span-1)

**Left Column (66%)**:

- **"Your Next Feed" Card**:
  - Header: Title + feed selector dropdown (if multiple feeds)
  - Badge: "X items ready"
  - Feed items preview (max 5):
    - Title (line-clamp-2)
    - Description (line-clamp-2)
    - Source name + time ago
    - Thumbnail (24x24)
    - Hover: bg-accent/50, border-primary/50
  - "View All X Items" button → `/content/library?feed_id={id}&status=ready_for_publish`
  - Footer: [Edit Feed] [Send Your First Newsletter]

**Right Column (33%, sticky top-6)**:

- **Public Link Share Card** (border-2, bg-primary/5):
  - Title: "Share Your Feed"
  - Input: `smartnews.example/f/{slug}` (readonly, font-mono)
  - Click input → auto-select text
  - Copy button → clipboard + "Copied!" toast
  - QR code button (opens modal)
  - Social share buttons (Twitter, Facebook, LinkedIn, Email)
  - Subscriber count badge (if > 0)

- **Profile Completion Card** (if incomplete, amber alert):
  - Title: "Complete Your Profile"
  - Description: "Add name, bio & avatar before sending"
  - Checklist: ✓ Name, ○ Bio, ○ Avatar
  - "Complete Profile →" button

- **Quick Actions Card**:
  - Add Content Sources
  - Edit Feed Settings
  - View Analytics (disabled until STATE 3)

**What to Hide**:

- Stats cards (no metrics until active)

#### 4. STATE 3: Active Creator Dashboard

**Stats Row** (full width, grid-cols-4):

- 4 simple metric cards:
  1. Total Feeds (just count)
  2. Subscribers (count + change indicator)
  3. Revenue (lifetime total)
  4. Open Rate or Engagement % (average)
- Each card: small icon, title, large number, optional change %
- NO sparklines, NO drill-downs, NO complex interactions

**Left Column**: Same as STATE 2, but:

- CTA changes to "Send Now" (not "Send Your First")
- Show next scheduled send time if applicable

**Right Column**: Same as STATE 2, plus:

- **Growth Tips Card**:
  - Add more sources for variety
  - Refine keywords for better curation
  - Check analytics (link to future advanced dashboard)
  - Create another feed

### UI/UX Requirements

#### 5. Responsive Layout

- **Mobile (< 1024px)**: Single column, stacked
- **Desktop (≥ 1024px)**: grid-cols-3 (left: col-span-2, right: col-span-1)
- Right column: `sticky top-6` on desktop
- All cards: shadcn Card component (CardHeader, CardContent, CardFooter)

#### 6. Public URL Sharing (Critical Feature)

- Input click → auto-select all text
- Copy button → `navigator.clipboard.writeText()`
- Success: Change button icon to checkmark for 2s + toast
- QR code: Open in Dialog/Modal (use shadcn Dialog)
- Social buttons: Open in new window with pre-filled share text

#### 7. Component Requirements

- Use ONLY shadcn/ui components
- NO custom card layouts
- NO external chart libraries
- Simple CSS animations only (hover, transitions)
