# Story 1.6.2: Frontend - Public Feed Item Detail Page

## Story Status: In Progress

## User Story

**As a** visitor or subscriber browsing feed content,
**I want** to view individual feed items on their own dedicated public page with full details and related content,
**so that** I can read the complete item information, discover related content, and easily subscribe to the feed if interested.

## Story Context

### Parent Story
This story extends **Story 1.6 - Subscriber Discovery & Experience** (completed, QA passed) and **Story 1.6.1 - Feed Gating** (ready for review).

### Business Goal
Improve content discoverability and subscription conversion by:
- Creating dedicated, shareable URLs for each feed item
- Providing full item details in an optimized viewing experience
- Showing related content to increase engagement
- Offering clear subscription CTAs for non-subscribers

### Current State
Feed items are only visible within their parent feed/newsletter pages. There's no way to:
- Share individual content items
- View a single item in detail
- Discover related content from an item
- Convert item viewers to feed subscribers

### Desired State
Each feed item has its own public page with:
- Unique shareable URL
- Full content details (title, image, description)
- Related content suggestions
- Subscribe button for non-subscribers
- Mobile-responsive design
- SEO-friendly structure

### URL Structure & Slug Generation

**URL Format**: `/feed/[creator-feed-name]/[item-title-slug]`

**Slug Generation Function**:
```typescript
// src/lib/utils/slug.ts
export function generateItemSlug(title: string): string {
  return title
    .toLowerCase()
    .trim()
    .replace(/[^\w\s-]/g, '') // Remove special characters
    .replace(/\s+/g, '-')      // Replace spaces with hyphens
    .replace(/-+/g, '-')       // Remove consecutive hyphens
    .substring(0, 60)          // Limit to 60 chars
}

// Usage
const itemUrl = `/feed/${feed.slug}/${generateItemSlug(item.title)}`
```

**Note**: Slug is for SEO/readability only. Actual data fetching uses content_hash:
1. Extract itemSlug from URL
2. Fetch feed items for that feed
3. Find item matching the slug (or use content_hash if stored)
4. Fetch full item details via `/feed-items/by-hash/{content_hash}`
