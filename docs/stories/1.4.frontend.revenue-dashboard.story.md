# Story 1.4: Frontend - Revenue Attribution & Tracking Dashboard

## Story Status: 🚀 Ready for Development

## User Story

As a creator with published feeds,
I want to see real-time revenue attribution, detailed earnings breakdowns, and payout history through an intuitive dashboard with interactive visualizations,
So that I can track my earnings transparently and make data-driven decisions to optimize my content strategy.

## Story Context

### Integration Points

- **Backend API**: FastAPI endpoints at `https://localhost:8000/`
- **Revenue API**: Estimation at `/creator/revenue/estimate` and `/creator/revenue/projections`
- **Subscription Tracking**: Creator subscribers at `/subscriptions/{creator_hash}/subscribers`
- **Analytics API**: Custom analytics endpoints (to be defined)
- **Attribution Links**: Generated through frontend with creator_hash parameter
- **Stripe Connect**: Payment processing (backend handles integration)

### Technology Stack

- **Framework**: Next.js 15.1 with App Router
- **Charts**: Recharts or Tremor for data visualization
- **UI Components**: shadcn/ui (Card, Tabs, Dialog, Table)
- **State Management**: React Query for data fetching, Zustand for filters
- **Data Export**: xlsx library for Excel exports
- **Real-time Updates**: WebSocket or polling for live metrics
- **Number Animation**: Framer Motion for smooth transitions

### Real-time Updates

```typescript
// Polling for live metrics
const { data: metrics } = useQuery({
  queryKey: ["revenue-metrics"],
  queryFn: fetchRevenueMetrics,
  refetchInterval: 30000, // 30 seconds
  refetchIntervalInBackground: true,
});

// WebSocket alternative
useEffect(() => {
  const ws = new WebSocket("wss://api/revenue/stream");
  ws.onmessage = (event) => {
    const update = JSON.parse(event.data);
    updateMetrics(update);
  };
  return () => ws.close();
}, []);
```

### Export Implementation

```typescript
import * as XLSX from "xlsx";

const exportToExcel = (data: RevenueBreakdown[]) => {
  const ws = XLSX.utils.json_to_sheet(data);
  const wb = XLSX.utils.book_new();
  XLSX.utils.book_append_sheet(wb, ws, "Revenue");
  XLSX.writeFile(wb, `revenue-${Date.now()}.xlsx`);
};
```

## Dependencies

- **Feeds**: At least one published feed (Story 1.3)
- **Stripe**: Stripe Connect must be configured

## Risks & Mitigation

- **Risk**: Real-time data causing performance issues
  - **Mitigation**: Implement smart polling and caching
- **Risk**: Complex calculations slowing dashboard
  - **Mitigation**: Pre-calculate on backend, cache results
- **Risk**: Chart library bundle size
  - **Mitigation**: Use tree-shaking, lazy load charts
