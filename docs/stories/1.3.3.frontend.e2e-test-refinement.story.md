## Story Context

### Background

Story 1.3.2 made a critical architectural change:

- **Removed** FilterConfigurationStep (Step 3) from Feed Creation wizard
- **Moved** keyword filtering from feed-level (Step 3) to source-level (Add Source dialog in Step 2)
- **Reduced** wizard from 5 steps to 4 steps

**Current Problem:**

- E2E test (`tests/e2e/creator/test_feed_creation.py`) still expects 5-step flow
- Test tries to interact with FilterConfigurationStep (lines 241-278) → **TEST FAILING**
- Test adds keywords at wrong point in flow (Step 3 instead of Step 2)

**User Request - Publishing Settings UX Improvements:**

User has identified 5 UX improvements needed in PublishSettingsStep:

1. ❌ Remove "Publish Immediately" option (all feeds published by default)
2. ✅ Move "Automatic Sending" toggle to the top
3. ✅ If Automatic Sending is OFF, HIDE delivery frequency options
4. ✅ Show message: "You'll need to manually send the feed to your subscribers each time — whenever you want"
5. ✅ Simplify to single toggle (remove redundant "Enable Scheduled Delivery")

**Pattern to Follow** (lines 209-273):

- Click "New Source" button

- Add good keywords: fill input → press Enter → verify badge appears
- Add bad keywords: fill input → press Enter → verify badge appears
- Set relevance score (if applicable)
- Select sync schedule from dropdown
- Click "Create Source" button

- Take screenshot for verification

**Key Implementation Details**:

- Use `page.locator('input#source-name')` for name field
- Use `page.locator('input#source-url')` for URL field
- Use `page.locator('input#good-keywords')` for good keywords input
