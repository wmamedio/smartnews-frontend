## User Story

As a feed creator,
I want to preview imported content with interactive rating (thumbs up/down) and refine source keywords based on actual content,
So that I can ensure my feeds only contain high-quality, relevant content before publishing to subscribers.

## Story Context

### Background

Stories 1.3.2, 1.3.3, and 1.3.4 established a solid feed creation workflow with source-level keyword filtering, a 4-step wizard, and delivery scheduling. However, creators currently have no way to:

- Preview what content was imported from a source before committing to it
- Interactively rate content (thumbs up/down) to refine AI filtering
- Refine source keywords based on actual imported content
- Preview their feed's content before final publication
- Filter library content by specific feeds
- Visually distinguish rejected content in the library

**Current State:**

- Source creation with keywords (Story 1.3.2) has no content preview
- Feed wizard has 4 steps: Basic Info → Sources → Publishing Settings → Review & Publish
- Library exists but lacks feed filtering and visual differentiation for rejected items
- No interactive content rating mechanism
- No keyword refinement workflow based on imported content

**User Request:**
Enhance the content preview and library experience with:

1. Content preview after adding a feed_source (show published + rejected items)
2. Thumbs up/down rating to adjust content status and refine keywords
3. Feed preview step in wizard (before scheduling)
4. Library filtering by feed_id
5. Feed tags on library cards
6. Visual differentiation for rejected content (40% opacity)

### What This Story Changes

**From (Story 1.3.4 State)**:

- No content preview after source creation
- Feed wizard: 4 steps (Basic Info → Sources → Publishing → Review)
- Library has no feed filtering

**NOT CHANGED** (Important):

2. **Visual Differentiation for Status** ✅

   - Rejected/disabled items: 40% opacity on image

   - Clear visual distinction between approved and rejected content

3. **Thumbs Up/Down Overlay** ✅
   - On card hover, show overlay with two action buttons:
     - Thumbs Up icon (green background)
     - Thumbs Down icon (red background)
   - Icons positioned top-right of card image
   - Smooth opacity transition on hover (0.9 opacity overlay)
   - Click action triggers rating workflow

4. **Thumbs Up Rating Workflow** ✅
   - Click thumbs up → Call PUT `/feed-items/{id}` with `status: "ready_to_publish"`
   - On success → Call GET `/feed-items/{id}` to fetch item with keywords
   - Display KeywordRefinementDialog:
     - Title: "Add Good Keywords to Source?"
     - Show extracted keywords as green badges (good keywords)
     - Checkboxes to select which keywords to add
     - Button: "Add Selected Keywords to Source"
     - Button: "Skip"
   - If keywords selected → Call PUT `/feed-sources/{source_id}` to append to `good_keywords`
   - Show alert: "Keywords added. Changes will only affect future content."
   - Update card status badge to "Ready to Publish"

5. **Thumbs Down Rating Workflow** ✅
   - Click thumbs down → Call PUT `/feed-items/{id}` with `status: "rejected"`
   - On success → Call GET `/feed-items/{id}` to fetch item with keywords
   - Display KeywordRefinementDialog:
     - Title: "Add Bad Keywords to Source?"
     - Show extracted keywords as red badges (bad keywords)
     - Checkboxes to select which keywords to add
     - Button: "Add Selected Keywords to Source"
     - Button: "Skip"
   - If keywords selected → Call PUT `/feed-sources/{source_id}` to append to `bad_keywords`
   - Show alert: "Keywords added. Changes will only affect future content."
   - Update card status badge to "Rejected"
   - Apply 40% opacity to card image

6. **API Integration** ✅

```
[Update Source] ← PUT /feed-sources/{id}

   ↓
```


### Feed Tags Display Logic

**Multiple Feeds Handling:**

```typescript
const renderFeedTags = (feeds: string[], maxDisplay = 2) => {
  if (feeds.length === 0) return <span className="text-xs text-muted-foreground">No feeds</span>;

  const displayFeeds = feeds.slice(0, maxDisplay);
  const remainingCount = feeds.length - maxDisplay;

  return (
    <>
      {displayFeeds.map(feed => (
        <Badge key={feed} variant="secondary">{feed}</Badge>
      ))}
      {remainingCount > 0 && (
        <Badge variant="outline" title={feeds.slice(maxDisplay).join(', ')}>
          +{remainingCount} more
        </Badge>
      )}
    </>
  );
};
```
