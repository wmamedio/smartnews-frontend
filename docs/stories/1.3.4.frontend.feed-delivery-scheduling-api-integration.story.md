## User Story

As a feed creator,
I want to configure delivery schedules when creating a feed (daily, weekly, bi-weekly, or monthly),
So that my subscribers receive content updates automatically at the right time and frequency.

## Story Context

### Background

The backend has implemented a full delivery scheduling system with endpoints for CRUD operations on feed schedules (POST, GET, DELETE `/feeds/{feed_id}/schedule`). Currently, the frontend's PublishSettingsStep only has basic toggle functionality but doesn't integrate with the scheduling API or provide frequency-specific configuration.

**Current State:**

- PublishSettingsStep shows "Automatic Sending" toggle (from Story 1.3.3)
- Basic frequency dropdown exists (Daily, Weekly, Bi-Weekly, Monthly)
- Send time picker exists (HH:MM format)
- No API integration with `/feeds/{feed_id}/schedule` endpoint
- Missing frequency-specific fields (days of week, day of month)
- No GET/DELETE functionality for managing existing schedules

**User Request:**
Implement full delivery scheduling in the feed creation wizard with:

1. Frequency-dependent conditional fields (days of week for weekly, day of month for monthly)
2. API integration: Create schedule after feed creation succeeds
3. Schedule preview functionality (show next 5 delivery times)
4. CRUD operations: View, Edit, Delete schedules (not just Create)
5. E2E test coverage for scheduling workflows

## Technical Notes

### Frequency Values (Backend API)

**API requires frequency in minutes**:

- Daily: `1440` minutes (24 hours)
- Weekly: `10080` minutes (7 days)
- Bi-Weekly: `20160` minutes (14 days)
- Monthly: `43200` minutes (30 days)

**Conversion**:

```typescript
const FREQUENCY_MINUTES = {
  daily: 1440,
  weekly: 10080,
  biweekly: 20160,
  monthly: 43200,
} as const;
```

### Days of Week Mapping

**Backend API uses numeric values**:

- 0 = Sunday
- 1 = Monday
- 2 = Tuesday
- 3 = Wednesday
- 4 = Thursday
- 5 = Friday
- 6 = Saturday

### Day of Month Special Value

**Last day of month**: `-1`

- Handles variable month lengths (28, 29, 30, 31 days)
- Backend calculates actual date

### Schedule Preview Format

**API returns array of ISO timestamps**:

```json
[
  "2025-01-27T09:00:00-08:00",
  "2025-02-03T09:00:00-08:00",
  "2025-02-10T09:00:00-08:00",
  "2025-02-17T09:00:00-08:00",
  "2025-02-24T09:00:00-08:00"
]
```

**Frontend formats for display**:

```typescript
new Date(timestamp).toLocaleString("en-US", {
  weekday: "short",
  year: "numeric",
  month: "short",
  day: "numeric",
  hour: "numeric",
  minute: "2-digit",
  timeZoneName: "short",
});
// Output: "Mon, Jan 27, 2025 at 9:00 AM PST"
```

### Schedule Display Formatting

**Helper Function: `formatScheduleDisplay(schedule)`**

```typescript
// Location: src/lib/utils/schedule-formatter.ts
function formatScheduleDisplay(schedule: DeliveryScheduleResponse | null): string {
  if (!schedule) return "Manual";

  const { frequency, delivery_time, delivery_days, delivery_day_of_month } = schedule;

  switch (frequency) {
    case 1440: // Daily
      return `Daily (${delivery_time})`;

    case 10080: // Weekly
      if (delivery_days && delivery_days.length === 1) {
        const dayName = [
          "Sunday",
          "Monday",
          "Tuesday",
          "Wednesday",
          "Thursday",
          "Friday",
          "Saturday",
        ][delivery_days[0]];
        return `Weekly (${dayName})`;
      }
      return `Weekly (${delivery_days?.length || 0} days)`;

    case 20160: // Bi-weekly
      return `Biweekly (${delivery_days?.length || 0} days)`;

    case 43200: // Monthly
      if (delivery_day_of_month === -1) {
        return "Monthly (Last Day)";
      }
      // Add ordinal suffix: 1st, 2nd, 3rd, 4th, etc.
      const day = delivery_day_of_month || 1;
      const suffix = day === 1 ? "st" : day === 2 ? "nd" : day === 3 ? "rd" : "th";
      return `Monthly (${day}${suffix})`;

    default:
      return "Manual";
  }
}
```

**Usage in components**:

- List View: `<span>{formatScheduleDisplay(feed.schedule)}</span>`
- Card View: `<Badge>{formatScheduleDisplay(feed.schedule)}</Badge>`

### API Integration Pattern

**Feed creation flow with schedule**:

```typescript
try {
  // 1. Create feed
  const feed = await createFeed(feedData);

  // 2. Create schedule (if configured)
  if (scheduleData) {
    await createFeedSchedule(feed.id, scheduleData);
    toast.success("Feed created with delivery schedule");
  } else {
    toast.success("Feed created successfully");
  }

  // 3. Redirect to feeds list
  router.push("/feeds");
} catch (error) {
  if (feed && !scheduleData) {
    // Feed created but schedule failed
    toast.warning("Feed created, but schedule setup failed");
    router.push("/feeds");
  } else {
    toast.error("Failed to create feed");
  }
}
```
