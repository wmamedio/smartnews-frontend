# Story 1.6.1: Frontend - Public Feed Page Content Gating

## Story Status: 👀 Ready for Review

**Related SCP**: [SCP-2025-004 - Public Feed Page Content Gating](../sprint-change-proposals/scp-2025-004-feed-page-gating.md)

## User Story

**As a** unsubscribed visitor to a public feed page,
**I want** to see a preview of the feed content with prominent creator information and a clear value proposition,
**so that** I understand what I'm subscribing to and am motivated to subscribe for free to access the full content.

**As a** subscribed user visiting a feed page,
**I want** to view all available content without conversion prompts,
**so that** I can efficiently consume the content I'm already subscribed to.

## Story Context

### Parent Story
This story extends **Story 1.6 - Subscriber Discovery & Experience** (completed, QA passed).

### Business Goal
Improve subscription conversion rate on public feed pages by:
- Creating clear value proposition for unsubscribed users
- Implementing content gating (preview mode) to create motivation to subscribe
- Removing friction for already-subscribed users

### Current State
The public feed page (`/feed/[slug]`) displays identical content to all users regardless of subscription status:
- All newsletters displayed with infinite scroll
- All content items shown for each newsletter
- Subscription button present but not compelling

### Desired State
Two distinct experiences based on subscription status:
1. **Unsubscribed users**: Preview mode with limited content + prominent creator info + clear CTAs
2. **Subscribed users**: Full access mode with all content, no conversion prompts

## Acceptance Criteria

### AC1: Unsubscribed User Preview Experience
- **Given**: User visits public feed page (e.g., `/feed/creator-slug`) without being subscribed
- **When**: Page loads
- **Then**: Display:
  - Creator information section (name, bio, photo, subscriber count, category)
  - Publishing frequency badge ("Daily" / "Weekly" / "Bi-weekly")
  - ONLY the most recent newsletter
  - ONLY the first 3 content items from that newsletter
  - Content teaser UI on 3rd item (blur/fade effect with "Subscribe to see more..." text)
  - Prominent CTA: "Subscribe FREE" (above content preview)
  - Prominent CTA: "Subscribe FREE — See Full Content" (below content preview with context)
  - Value proposition text: "Get [frequency] newsletters with curated [category] content"
  - Context message: "Preview: Showing the most recent newsletter (X total newsletters available)"
  - Infinite scroll disabled
- ✅ **Verified**: Unsubscribed users see limited preview with clear subscription value

### AC2: Subscribed User Full Access Experience
- **Given**: User visits public feed page while authenticated AND subscribed to that feed
- **When**: Page loads
- **Then**: Display:
  - Minimized creator info (name/avatar only in header)
  - ALL newsletters with infinite scroll (current behavior from Story 1.6)
  - ALL content items for each newsletter
  - NO subscription CTAs or prompts
  - "Subscribed" badge in header (current behavior)
  - Standard content count display: "Showing X of Y newsletters"
- ✅ **Verified**: Subscribed users have full content access without conversion friction

### AC3: Authenticated Non-Subscriber Experience
- **Given**: User is authenticated but NOT subscribed to the feed
- **When**: Page loads
- **Then**: Behave as unsubscribed user (preview mode from AC1)
- **And**: Subscribe button triggers immediate subscription (no auth modal)
- ✅ **Verified**: Authenticated non-subscribers see preview and can subscribe directly

### AC4: Unauthenticated User Experience
- **Given**: User is not authenticated
- **When**: User clicks "Subscribe" button
- **Then**: Display AuthModal prompting sign up or log in
- **And**: After authentication, return to feed page and auto-complete subscription
- ✅ **Verified**: Unauthenticated users are guided through auth flow before subscribing

### AC5: Creator Information Display (Preview Mode)
- **Given**: Unsubscribed user viewing feed page in preview mode
- **When**: Creator section rendered
- **Then**: Display should include:
  - Creator avatar (large, 80x80px with ring styling)
  - Creator name (prominent, 2xl font size)
  - Creator bio/description (if available, 2-line clamp)
  - Subscriber count badge (if > 0)
  - Category badge
  - Clear visual hierarchy in Card component with gradient background
- ✅ **Verified**: Creator identity and value prop clearly communicated

### AC6: Content Teaser UI
- **Given**: Preview mode displaying 3 content items
- **When**: 3rd (last) item rendered
- **Then**: Apply visual teaser effect:
  - Blur/fade gradient overlay (background gradient from transparent → muted)
  - Centered text: "Subscribe to see more content..."
  - "Read More" link hidden on last item only
  - First 2 items display normally without overlay
- ✅ **Verified**: Content teaser creates clear visual indication of limited preview

### AC7: Responsive Design
- **Given**: User accesses feed page on any device
- **When**: Page renders
- **Then**: Design adapts properly:
  - Mobile (375px+): Single column, stacked layout, creator section centered
  - Tablet (768px+): Responsive flex layout
  - Desktop (1024px+): Side-by-side layout where applicable
  - Touch targets meet 44px minimum on mobile
- ✅ **Verified**: Page is fully responsive across all breakpoints

  - Build: `npm run build` succeeds
  - Lint: `npm run lint` passes
