# Story 1.8: Frontend - Creator Profile & Account Settings

## Story Status: ✅ Ready for Review

**Priority**: HIGH - Next Sprint

## User Story

As an authenticated creator,
I want to manage my profile information, update my account security settings, and configure my preferences through a comprehensive settings interface,
So that I can maintain accurate personal information, secure my account, and customize my platform experience.

## Story Context

### Integration Points

- **Backend API**: FastAPI endpoints at `http://50.116.23.104:8000`
- **Profile API**: Creator profile at `/creator/profile` (GET, POST, PUT)
- **File Upload**: Avatar/photo upload at `/creator/profile/upload` (POST multipart/form-data)
- **Auth API**: Current user at `/auth/me`, token refresh at `/auth/refresh`
- **Social API**: OAuth connections at `/social/{provider}/redirect` and `/social/{provider}/callback`
- **Password Change**: (Endpoint TBD - check backend docs)
- **Email Update**: (Endpoint TBD - check backend docs)

### Technology Stack

- **Framework**: Next.js 15.1 with App Router
- **UI Components**: shadcn/ui (Form, Card, Dialog, Tabs, Avatar, Input, Textarea)
- **Forms**: React Hook Form + Zod validation (reuse existing schemas)
- **State Management**: Zustand auth store (extend for profile), React Query for server state
- **File Upload**: react-dropzone for avatar upload with image cropping
- **Image Handling**: next/image for optimized avatars
- **Validation**: Existing `profileSetupSchema` from `src/lib/schemas/profile.ts`

## Acceptance Criteria

### Functional Requirements

1. **Profile Information Management (AC1)**
   - View current profile (name, bio, avatar, categories, website, location)
   - Edit profile fields with real-time validation
   - Upload and crop avatar/profile photo
   - Preview changes before saving
   - Success confirmation after save
   - Revert to previous values with cancel button

2. **Account Security Settings (AC2)**
   - Change password with current password verification
   - Password strength indicator
   - Email address update with verification flow
   - Two-factor authentication toggle (if backend supports)
   - View active sessions (if backend supports)
   - Account deletion request (with confirmation)

3. **Social Media Connections (AC3)**
   - View currently connected social accounts
   - Connect new social accounts (YouTube, Twitter, Reddit)
   - Disconnect social accounts with confirmation
   - Display connection status and last sync time
   - Show follower counts from connected platforms
   - Revenue estimation recalculates on social changes

4. **Notification Preferences (AC4)**
   - Email notification settings (new subscribers, revenue milestones, etc.)
   - Push notification preferences
   - Content delivery preferences
   - Marketing email opt-in/out
   - Frequency settings (immediate, daily digest, weekly)
   - Save preferences to backend

5. **Privacy & Display Settings (AC5)**
   - Profile visibility (public/private)
   - Show/hide subscriber count
   - Show/hide revenue statistics
   - Data export request
   - Privacy policy and terms acceptance tracking
   - Cookie preferences

### UI/UX Requirements

6. **Settings Navigation (AC6)**
   - Tabbed interface for different setting categories
   - Sidebar navigation on desktop
   - Breadcrumb navigation
   - Unsaved changes warning when navigating away
   - Mobile-friendly stacked layout
   - Active tab highlighting

7. **Form Validation & Feedback (AC7)**
   - Inline validation errors
   - Real-time field validation
   - Success toast notifications
   - Error toast notifications with retry option
   - Loading states during save operations
   - Disabled state for required fields

8. **Responsive Design (AC8)**
   - Mobile: Single column with full-width forms
   - Tablet: Two-column layout for longer forms
   - Desktop: Sidebar + content area
   - Touch-optimized inputs on mobile
   - Accessible on all screen sizes
   - Keyboard navigation support
