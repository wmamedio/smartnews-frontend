# Story 1.3.6: Frontend - AI-Powered Description & Category Generation

## Story Status: Done ✅

## Parent Story

**Story 1.3**: Frontend - Feed Creation & Publication System (✅ Done)

## User Story

As an approved creator,
I want the system to automatically generate my feed description and category suggestions based on my feed name and selected sources,
So that I can quickly publish my feed without having to manually write a description or think about categorization.

## Story Context

### Background

Story 1.3 successfully implemented the 5-step feed creation wizard. However, user feedback and new backend AI capabilities identified an opportunity to improve the UX by moving description and category fields from Step 1 to the final step, where the system can intelligently generate suggestions based on the feed's actual content sources.

### What Exists Already

**✅ Feed Creation Wizard (COMPLETE - Story 1.3)**:
- 5-step wizard: Basic Info → Source Selection → Content Preview → Publishing Settings → Review
- Current Step 1 collects: name, description, category
- All wizard components implemented and working
- Draft save functionality operational

**✅ Backend API (NEW - Available)**:
- `GET /feeds/{feed_id}/suggestions` endpoint operational
- Returns AI-generated description + 1-3 category suggestions
- Analyzes feed name and selected sources
- Max 500 characters for description
- Categories from Google AdSense taxonomy

### What Needs to Change

**Step 1 (BasicInfoStep)**:
- Remove description textarea
- Remove category dropdown
- Keep only feed name input

**Step 3 → Step 4 transition**:
- Auto-save draft feed via `POST /feeds/`
- Store returned `feed_id` in wizard state

**Step 4 (PublishSettingsStep)**:
- Add prefetch logic on component mount
- Call `GET /feeds/{feed_id}/suggestions` in background
- User configures schedule while API loads

**Step 5 (ReviewStep → AIDescriptionReviewStep)**:
- Display pre-loaded AI suggestions (zero wait time)
- Allow user to edit description
- Allow user to select/change category
- Final save via `PUT /feeds/{feed_id}` with approved data

### Integration Points

- **Backend API**:
  - `GET /feeds/{feed_id}/suggestions` - AI generation
  - `POST /feeds/` - Draft creation after Step 3
  - `PUT /feeds/{feed_id}` - Final save with description/category
- **API Client**: `src/lib/api/feeds.ts` or `src/lib/api/services/feeds.service.ts`
- **Wizard Components**: All 5 steps in `src/components/feeds/wizard/`
- **Feed Builder Store**: Zustand store for wizard state
- **State Management**: React Query for API caching and prefetching

### Technology Stack

- **Framework**: Next.js 15.5+ with App Router
- **UI Components**: shadcn/ui (Card, Dialog, Textarea, Select, Alert)
- **State Management**:
  - Zustand for wizard state (`useFeedBuilderStore`)
  - React Query for API state, caching, and prefetching
- **Forms**: React Hook Form + Zod validation
- **Notifications**: Sonner toast library
- **Icons**: Lucide React (Sparkles for AI, AlertCircle for errors)

**File**: `src/components/feeds/wizard/PublishSettingsStep.tsx`

**Add Prefetch Logic**:

```typescript
import { useQueryClient } from '@tanstack/react-query';
import { getFeedSuggestions } from '@/lib/api/feeds';
import { useFeedBuilderStore } from '@/lib/stores/feed-builder-store';

export function PublishSettingsStep() {
  const queryClient = useQueryClient();
  const feedId = useFeedBuilderStore((state) => state.feedId);

  useEffect(() => {
    // Prefetch AI suggestions in background when Step 4 loads
    if (feedId) {
      console.log('[Step 4] Prefetching AI suggestions for feed:', feedId);

      queryClient.prefetchQuery({
        queryKey: ['feed-suggestions', feedId],
        queryFn: () => getFeedSuggestions(feedId),
        staleTime: 5 * 60 * 1000, // Cache for 5 minutes
      });
    }
  }, [feedId, queryClient]);

  // ... rest of component (schedule configuration UI - no changes)
}
```

### 3. AIDescriptionReviewStep Component (New)

**File**: `src/components/feeds/wizard/AIDescriptionReviewStep.tsx` (formerly ReviewStep.tsx)

**New Component Structure**:
```typescript
'use client';

import { useState, useEffect } from 'react';
import { useQuery } from '@tanstack/react-query';
import { Sparkles, AlertCircle } from 'lucide-react';
import { Card, CardContent, CardDescription, CardHeader, CardTitle } from '@/components/ui/card';
import { Label } from '@/components/ui/label';
import { Textarea } from '@/components/ui/textarea';
import { Select, SelectContent, SelectItem, SelectTrigger, SelectValue } from '@/components/ui/select';
import { Skeleton } from '@/components/ui/skeleton';
import { Alert, AlertDescription } from '@/components/ui/alert';
import { Button } from '@/components/ui/button';
import { useFeedBuilderStore } from '@/lib/stores/feed-builder-store';
import { getFeedSuggestions } from '@/lib/api/feeds';

export function AIDescriptionReviewStep() {
  const { feedId, feed, setFeed } = useFeedBuilderStore();

  const [description, setDescription] = useState(feed.description || '');
  const [category, setCategory] = useState(feed.category || '');

  // Fetch AI suggestions (data should already be cached from Step 4 prefetch)
  const {
    data: suggestions,
    isLoading,
    isError,
    refetch
  } = useQuery({
    queryKey: ['feed-suggestions', feedId],
    queryFn: () => getFeedSuggestions(feedId!),
    enabled: !!feedId,
    retry: 2,
  });

  // Auto-populate with AI suggestions when loaded
  useEffect(() => {
    if (suggestions && !description) {
      setDescription(suggestions.description);
      setFeed({ ...feed, description: suggestions.description });
    }
    if (suggestions && !category && suggestions.suggested_categories.length > 0) {
      const firstCategory = suggestions.suggested_categories[0];
      setCategory(firstCategory);
      setFeed({ ...feed, category: firstCategory });
    }
  }, [suggestions]);

  const handleDescriptionChange = (value: string) => {
    setDescription(value);
    setFeed({ ...feed, description: value });
  };

  const handleCategoryChange = (value: string) => {
    setCategory(value);
    setFeed({ ...feed, category: value });
  };

  return (
    <div className="space-y-6">
      {/* AI Suggestions Card */}
      <Card>
        <CardHeader>
          <div className="flex items-center gap-2">
            <Sparkles className="h-5 w-5 text-primary" />
            <CardTitle>AI-Generated Suggestions</CardTitle>
          </div>
          <CardDescription>
            Based on your feed name and sources. You can edit before publishing.
          </CardDescription>
        </CardHeader>
        <CardContent className="space-y-4">
          {/* Loading State */}
          {isLoading && (
            <div className="space-y-4">
              <div>
                <Label>Description</Label>
                <Skeleton className="h-24 w-full" />
              </div>
              <div>
                <Label>Category</Label>
                <Skeleton className="h-10 w-full" />
              </div>
            </div>
          )}

          {/* Error State */}
          {isError && (
            <Alert variant="destructive">
              <AlertCircle className="h-4 w-4" />
              <AlertDescription>
                Failed to generate AI suggestions. You can enter manually below.
                <Button
                  variant="link"
                  onClick={() => refetch()}
                  className="ml-2"
                >
                  Retry
                </Button>
              </AlertDescription>
            </Alert>
          )}

          {/* Success State - Editable Fields */}
          {!isLoading && (
            <>
              <div>
                <Label htmlFor="ai-description">Description</Label>
                <Textarea
                  id="ai-description"
                  value={description}
                  onChange={(e) => handleDescriptionChange(e.target.value)}
                  placeholder="Describe your feed..."
                  maxLength={500}
                  rows={4}
                  className="resize-none"
                />
                <p className="text-sm text-muted-foreground mt-1">
                  {description.length}/500 characters
                </p>
              </div>

              <div>
                <Label htmlFor="ai-category">Category</Label>
                <Select value={category} onValueChange={handleCategoryChange}>
                  <SelectTrigger id="ai-category">
                    <SelectValue placeholder="Select a category" />
                  </SelectTrigger>
                  <SelectContent>
                    {suggestions?.suggested_categories.map((cat) => (
                      <SelectItem key={cat} value={cat}>
                        {cat}
                      </SelectItem>
                    ))}
                  </SelectContent>
                </Select>
                {suggestions && (
                  <p className="text-sm text-muted-foreground mt-1">
                    AI suggested {suggestions.suggested_categories.length} {suggestions.suggested_categories.length === 1 ? 'category' : 'categories'}
                  </p>
                )}
              </div>
            </>
          )}
        </CardContent>
      </Card>

      {/* Existing Review Sections */}
      {/* ... feed summary, sources, filters, schedule ... */}
    </div>
  );
}
```

**Estimated Changes**: ~150 lines (new component)

```typescript
/**
 * Get AI-powered description and category suggestions for a feed
 *
 * Endpoint: GET /feeds/{feed_id}/suggestions
 *
 * @param feedId - The feed ID (must be owned by current creator)
 * @returns AI-generated description and 1-3 category suggestions
 * @throws {AxiosError} If feed not found (404), unauthorized (401), or server error (500)
 */
export async function getFeedSuggestions(
  feedId: number
): Promise<{
  description: string;
  suggested_categories: string[];
}> {
  try {
    const { data } = await apiClient.get(`/feeds/${feedId}/suggestions`);
    return data;
  } catch (error) {
    console.error('[API] Failed to get feed suggestions:', error);
    throw error;
  }
}
```
