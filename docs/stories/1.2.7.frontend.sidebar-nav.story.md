## User Story

**As a** creator,
**I want** content management sections (Sources, Import, Library) accessible via sidebar navigation,
**so that** I have consistent navigation patterns and better vertical space utilization.

---

## Story Context

### Background

**Type:** UX Enhancement / Navigation Restructuring (Brownfield)

Current content page uses horizontal tab navigation (Sources | Import | Library) in the main content area. This Sprint Change Proposal moves these tabs into the left sidebar as nested navigation items under "Content" for:

1. Better navigation discoverability
2. More efficient vertical space usage
3. Consistent navigation pattern across the application

**Reference:** Sprint Change Proposal completed by BMad Master (2025-10-01) - Full analysis in conversation history

### Existing System Integration

- **Integrates with:** Story 1.2.5 dashboard layout (app-sidebar.tsx)
- **Technology:** Next.js 15.5 App Router, shadcn/ui Sidebar components
- **Follows pattern:** Nested sidebar navigation (like other dashboard apps)
- **Touch points:**
  - `src/components/layout/app-sidebar.tsx` (add nested nav)
  - `src/app/(creator)/content/` (split into sub-routes)

### Key Decision

This is a **UI-only refactoring** - no functional changes to Story 1.2 or Story 1.2.6 features. All existing components are moved as-is to new page routes.

## Technical Notes

### Integration Approach

**Sidebar Update:**

```typescript
// src/components/layout/app-sidebar.tsx

import { Collapsible, CollapsibleContent, CollapsibleTrigger } from "@/components/ui/collapsible";
import { ChevronRight, FileText, Upload, Library } from "lucide-react";

const navItems = [
  { title: "Dashboard", url: "/dashboard", icon: LayoutDashboard },
  {
    title: "Content",
    url: "/content",
    icon: BookOpen,
    items: [
      { title: "Sources", url: "/content/sources", icon: FileText },
      { title: "Import", url: "/content/import", icon: Upload },
      { title: "Library", url: "/content/library", icon: Library },
    ],
  },
  { title: "Feeds", url: "/feeds", icon: Rss },
  { title: "Revenue", url: "/revenue", icon: DollarSign },
];

// In render, detect if item has nested items and use Collapsible
```

**Page Routes:**

- Use standard Next.js App Router nested routes
- Each page follows existing pattern (header + SidebarTrigger + content)
- No layout.tsx needed (already exists at (creator) level)

### Existing Pattern Reference

Follow the pattern established in:

- Story 1.2.5: `src/app/(creator)/dashboard/page.tsx` (header with SidebarTrigger)
