### DeleteFeedDialog Component (NEW)

**File**: `src/components/feeds/dialogs/DeleteFeedDialog.tsx`

**Purpose**: Reusable confirmation dialog for feed deletion with safety warnings

**Props Interface**:

```typescript
interface DeleteFeedDialogProps {
  feed: Feed; // Feed object to delete
  onDeleteSuccess: () => void; // Callback after successful deletion
  trigger?: React.ReactNode; // Custom trigger button (optional)
}
```

**Features**:

- Controlled dialog state with `useState(open, isDeleting)`
- Feed name display in destructive alert
- Conditional warning for published feeds
- Loading state during API call
- Error handling with try/catch
- Toast notifications (success/error with descriptions)
- Custom trigger support OR default ghost button with Trash2 icon
- Dialog auto-closes on successful deletion
- Cancel button to abort operation

**Dependencies**:

- `@/components/ui/dialog` - Dialog primitives (shadcn/ui)
- `@/components/ui/button` - Button component
- `@/components/ui/alert` - Alert component for warnings
- `@/lib/api/feeds` - `deleteFeed()` API function
- `sonner` - Toast notifications
- `lucide-react` - Icons (Trash2, AlertTriangle)

**API Integration**:

```typescript
const handleDelete = async () => {
  setIsDeleting(true);
  try {
    await deleteFeed(feed.id);
    toast.success("Feed deleted successfully", {
      description: `"${feed.name}" has been permanently removed.`,
    });
    setOpen(false);
    onDeleteSuccess(); // Triggers cache invalidation
  } catch (error: any) {
    toast.error("Failed to delete feed", {
      description: error.response?.data?.detail || "Please try again.",
    });
  } finally {
    setIsDeleting(false);
  }
};
```

**Styling Guidelines**:

- Dialog: Standard shadcn/ui dialog styling
- Alert: `variant="destructive"` for warnings
- Delete button: `variant="destructive"` (red)
- Cancel button: `variant="outline"` (gray)
- Default trigger: `variant="ghost"` with `text-destructive` icon
- Feed name: `<strong>` tag for emphasis
