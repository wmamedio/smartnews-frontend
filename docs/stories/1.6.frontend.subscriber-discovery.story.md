# Story 1.6: Frontend - Subscriber Discovery & Experience

## Story Status: 🚀 Ready for Development

## User Story

As a potential or existing subscriber,
I want to discover free content feeds, preview their quality, subscribe with simple frequency preferences, and view my subscriptions in a dashboard,
So that I can efficiently access high-quality curated content that matches my interests without complexity or payment barriers.

## Story Context

### Integration Points

- **Backend API**: FastAPI endpoints at `process.env.NEXT_PUBLIC_API_URL`
- **Discovery API**: Browse public feeds at `/feeds/public` (unauthenticated)
- **Subscriptions API**: Manage at `/subscriptions/` (POST to subscribe, DELETE to unsubscribe, PATCH for frequency)
- **My Subscriptions API**: List user's subscriptions at `/subscriptions/my-feeds`
- **Feed Content API**: View feed content at `/feeds/{feed_id}/items` (authenticated for subscribed feeds)

### Technology Stack

- **Framework**: Next.js 15+ with App Router
- **UI Components**: shadcn/ui components (search MCP before building)
- **Styling**: TailwindCSS with color variables from globals.css only
- **State Management**: React Context + Server Components
- **API Client**: Fetch with `process.env.NEXT_PUBLIC_API_URL`
- **Authentication**: JWT tokens (from Story 1.1)

## Acceptance Criteria

### Functional Requirements

1. **Feed Discovery Interface** (Phase 1)
   - Browse all public feeds without authentication
   - Display feed cards with: title, description, category, creator name, publish frequency
   - Search by feed name or creator name
   - Category-based filtering
   - "Subscribe" button on each feed card
   - Clicking "Subscribe" when not logged in redirects to login/signup

2. **Authentication for Subscribe Action** (Phase 2)
   - Unauthenticated users clicking "Subscribe" see modal: "Sign up or log in to subscribe"
   - Modal has two CTAs: "Sign Up" and "Log In"
   - Both redirect to appropriate auth pages (Story 1.1)
   - After successful auth, user returns to feed and subscription auto-completes

3. **My Subscriptions Dashboard** (Phase 3)
   - Authenticated users see "My Subscriptions" page
   - List all active subscriptions with feed cards
   - Each card shows: feed name, creator, current frequency setting, subscription date
   - Empty state message: "You haven't subscribed to any feeds yet. Browse feeds to get started."
   - "Browse Feeds" CTA button

4. **Subscription Actions Menu** (Phase 4)
   - Each subscription card has vertical 3-dots menu icon
   - Menu options:
     - "Edit Frequency" - Opens modal to change delivery frequency
     - "View Content" - Redirects to feed content page
     - "Unsubscribe" - Shows confirmation, then removes subscription
   - Menu accessible via keyboard (Tab + Enter)

5. **View Feed Content** (Phase 5)
   - Clicking "View Content" navigates to `/feeds/{feed_id}/content`
   - Displays feed items in chronological order (most recent first)
   - Each item shows: title, summary, published date, "Read More" link
   - "Read More" opens item in new tab or modal
   - Back button returns to subscriptions dashboard

### UI/UX Requirements

6. **Discovery Page Design**
   - Use shadcn Card component for feed cards
   - Responsive grid: 1 column (mobile), 2 columns (tablet), 3 columns (desktop)
   - Skeleton loaders while fetching feeds
   - "Subscribe" button uses shadcn Button with primary styling
   - Category filters use shadcn ToggleGroup or Tabs component

7. **Subscription Dashboard Design**
   - Use shadcn Card for subscription cards
   - Each card has shadcn DropdownMenu for 3-dot actions
   - Empty state uses shadcn Alert or custom EmptyState component
   - Status indicators use shadcn Badge component

8. **Frequency Override Modal**
   - Use shadcn Dialog component
   - Radio group options: "Use creator's frequency (Daily)" or "Custom frequency"
   - Custom options: Daily, Weekly, Bi-weekly (use shadcn RadioGroup)
   - Confirm/Cancel buttons at bottom

9. **Mobile Optimization**
   - Touch-optimized buttons (min 44px tap target)
   - Responsive breakpoints: sm → md → lg → xl
   - Bottom navigation or fixed header for mobile
   - Swipe gestures not required for MVP

## Technical Notes

### Subscribe Button Logic

```typescript
// components/subscriber/discovery/SubscribeButton.tsx
"use client";

import { Button } from "@/components/ui/button";
import { useAuth } from "@/lib/auth/useAuth";
import { useRouter } from "next/navigation";

export function SubscribeButton({ feedId }: { feedId: number }) {
  const { isAuthenticated } = useAuth();
  const router = useRouter();

  const handleSubscribe = async () => {
    if (!isAuthenticated) {
      // Show login modal or redirect
      router.push(`/login?redirect=/discover&action=subscribe&feedId=${feedId}`);
      return;
    }

    // Call subscribe API
    const response = await fetch(`${process.env.NEXT_PUBLIC_API_URL}/subscriptions/`, {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ feed_id: feedId, frequency: "daily" }), // Default to daily
    });

    if (response.ok) {
      // Show success toast
      toast.success("Subscribed successfully!");
    }
  };

  return (
    <Button onClick={handleSubscribe}>
      Subscribe
    </Button>
  );
}
```

### Frequency Override Modal

```typescript
// components/subscriber/subscriptions/FrequencyModal.tsx
"use client";

import { Dialog, DialogContent, DialogHeader, DialogTitle } from "@/components/ui/dialog";
import { RadioGroup, RadioGroupItem } from "@/components/ui/radio-group";
import { Label } from "@/components/ui/label";
import { Button } from "@/components/ui/button";

export function FrequencyModal({ subscription, open, onClose }: Props) {
  const [frequency, setFrequency] = useState(subscription.frequency);

  const handleSave = async () => {
    const response = await fetch(`${process.env.NEXT_PUBLIC_API_URL}/subscriptions/${subscription.id}`, {
      method: "PATCH",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ frequency }),
    });

    if (response.ok) {
      toast.success("Frequency updated!");
      onClose();
    }
  };

  return (
    <Dialog open={open} onOpenChange={onClose}>
      <DialogContent>
        <DialogHeader>
          <DialogTitle>Edit Delivery Frequency</DialogTitle>
        </DialogHeader>
        <RadioGroup value={frequency} onValueChange={setFrequency}>
          <div className="flex items-center space-x-2">
            <RadioGroupItem value="daily" id="daily" />
            <Label htmlFor="daily">Daily</Label>
          </div>
          <div className="flex items-center space-x-2">
            <RadioGroupItem value="weekly" id="weekly" />
            <Label htmlFor="weekly">Weekly</Label>
          </div>
          <div className="flex items-center space-x-2">
            <RadioGroupItem value="bi-weekly" id="bi-weekly" />
            <Label htmlFor="bi-weekly">Bi-weekly</Label>
          </div>
        </RadioGroup>
        <div className="flex justify-end space-x-2">
          <Button variant="outline" onClick={onClose}>Cancel</Button>
          <Button onClick={handleSave}>Save</Button>
        </div>
      </DialogContent>
    </Dialog>
  );
}
```
