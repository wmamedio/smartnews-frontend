## User Story

As an approved creator,
I want to import and manage content from multiple sources through an intuitive interface with real-time feedback,
So that I can efficiently build and maintain a comprehensive content library for my feeds with minimal friction.

## Story Context

### Integration Points

- **Backend API**: FastAPI endpoints at `https://localhost:8000/`
- **Feed Sources API**: CRUD operations at `/feed-sources/` endpoints
- **Feed Items API**: Content management at `/feed-items/` with pagination and filtering
- **Social Media API**: Connected accounts at `/feed-sources/social-media/connected`
- **Pull Content API**: Trigger content import at `/feed-items/{feed_source_id}/pull`
- **Bulk Actions API**: Batch operations at `/feed-items/bulk-action`

### Technology Stack

- **Framework**: Next.js 15.1 with App Router
- **UI Components**: shadcn/ui components (Card, Dialog, DataTable, Tabs)
- **Layout**: shadcn/ui dashboard-01 block with left sidebar navigation
- **State Management**: React Query for server state, Zustand for UI state
- **Forms**: React Hook Form + Zod validation
- **File Upload**: react-dropzone for drag-and-drop file uploads
- **Data Grid**: TanStack Table for content management
- **Real-time Updates**: Server-Sent Events for import progress

```typescript
  queryKey: ["feedItems", filters],
  queryFn: () => fetchFeedItems(filters),
  staleTime: 30000, // 30 seconds
});

// Optimistic updates for better UX
const mutation = useMutation({
  mutationFn: updateFeedItem,
  onMutate: async (newData) => {
    // Optimistically update cache
    await queryClient.cancelQueries(["feedItems"]);
    const previous = queryClient.getQueryData(["feedItems"]);
    queryClient.setQueryData(["feedItems"], optimisticUpdate);
    return { previous };
  },
});
```
