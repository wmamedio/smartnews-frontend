# Story 1.7: Frontend - Basic Admin & Content Moderation

## Story Status: 🚀 Ready for Development

## User Story

As a platform administrator,
I want to access a secure admin dashboard where I can approve/reject creator applications, moderate flagged content, monitor platform health, and manage user accounts,
So that I can maintain platform quality, ensure compliance, and provide a safe environment for all users.

## Story Context

### Integration Points

- **Backend API**: FastAPI endpoints at `https://localhost:8000/`
- **Authentication**: Admin-specific auth endpoints at `/admin/auth/login` with elevated privileges
- **Creator Management**: `/admin/creators` for application queue, `/admin/creators/{id}/approve`, `/admin/creators/{id}/reject`
- **Content Moderation**: `/admin/content/flagged`, `/admin/content/{id}/moderate`, `/admin/content/reports`
- **User Management**: `/admin/users`, `/admin/users/{id}/suspend`, `/admin/users/{id}/restore`
- **Platform Monitoring**: `/admin/metrics`, `/admin/health`, `/admin/revenue/summary`
- **Audit Logs**: `/admin/audit-logs` for compliance tracking

### Technology Stack

- **Framework**: Next.js 15.1 with App Router
- **UI Components**: shadcn/ui (dashboard-01 block for admin layout)
- **State Management**: Zustand for admin session, React Query for server state
- **Tables**: TanStack Table v8 for data grids
- **Charts**: Recharts for metrics visualization
- **Forms**: React Hook Form + Zod validation
- **Real-time**: Server-Sent Events for live metrics
- **Authorization**: Role-based access control (RBAC)

11. **Protected Admin Routes**

    ```typescript
    // middleware.ts addition
    export function middleware(request: NextRequest) {
      const adminToken = request.cookies.get("admin_token");
      const path = request.nextUrl.pathname;

      if (path.startsWith("/admin") && !adminToken) {
        return NextResponse.redirect(new URL("/admin/login", request.url));
      }

      // Verify admin role from JWT
      if (adminToken && !verifyAdminRole(adminToken)) {
        return NextResponse.redirect(new URL("/unauthorized", request.url));
      }
    }
    ```

### Performance Considerations

- Implement virtual scrolling for large tables
- Use server-side pagination (limit 50 rows)
- Cache frequently accessed metrics
- Debounce real-time updates to prevent flicker
- Lazy load chart libraries

## Risks & Mitigation

- **Risk**: Unauthorized admin access
  - **Mitigation**: Two-factor auth, IP allowlisting, session monitoring
- **Risk**: Accidental bulk operations
  - **Mitigation**: Confirmation dialogs, undo capability, audit trails
- **Risk**: Performance with large datasets
  - **Mitigation**: Server-side processing, pagination, caching

## Success Metrics

- Admin action completion time <5 seconds
- Zero unauthorized access incidents
- 100% audit log capture rate
- <1% false positive moderation rate
- Dashboard load time <2 seconds
